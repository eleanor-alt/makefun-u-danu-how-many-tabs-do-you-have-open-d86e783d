How many tabs do I have open? **127.**

Not a round guess like 100 (round numbers read as invented), not an absurd shock figure like 99999 (no one believes it), and not a small tidy count like 12. 127 is high enough to surprise, specific enough to sound counted rather than picked, and low enough that a real person — three windows, a research rabbit hole, and a "read later" pile they will never read — could genuinely have it open right now. The program writes that one number, digits only, to `/output/entry.txt`, guarded by a validation that enforces the competition gate (1–5 characters, digits only, not whitespace) before anything is written.

## Run it

```sh
python3 main.py
```
